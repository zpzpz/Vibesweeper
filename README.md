# Vibesweeper
I wanted to test out how good Big Pickle was at decompilation, so I threw it at Minesweeper. Here is the result. It works pretty well. It uses rusts eframe GUI and so it should be fairly cross-platform. I wanted it to run natively on Linux/Wayland

# Usage
```
./minesweeper
```

# Building
```
git clone 
cd Vibesweeper
cargo build
```
